# Space-Puzzle-Game

A first-person narrative exploration prototype built for ECS657U/ECS7003P Multi-platform Game Development.

## Concept

Your spaceship has crashed on an unknown planet. To escape, you must explore the surroundings, collect scattered spaceship parts, and return to your ship before your oxygen reserves run out — all while avoiding the creatures that roam the area.

## How to play

**Objective:** Collect all 5 spaceship parts scattered around the environment, then return to the spaceship to repair it and escape, before your oxygen reaches 0%.

**Controls:**

| Action | Key |
| --- | --- |
| Move | W / A / S / D |
| Look around | Mouse |
| Interact | E |

**Rules:**
- Your oxygen depletes continuously — keep an eye on the oxygen counter on screen.
- If oxygen reaches 0%, the game ends (Game Over).
- Avoid the creatures — if one catches you, the game ends immediately.
- Once you've collected all 5 parts, head back to the spaceship to win.

## Third-party / AI usage

This project uses only Unity's built-in primitives and basic assets — no external or self-created art assets. TextMesh Pro is Unity's bundled package.

## Running the project

1. Clone this repository.
2. Open the `Space game` folder with Unity Hub (Unity 2023.1.22f1).
3. Open the `SpaceExploration` scene under `Assets/Scenes`.
4. Press Play.
